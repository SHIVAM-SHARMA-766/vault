About

A password manager that assumes the worst about itself

Vault is built and run by one person, on infrastructure that costs nothing, with the goal that compromising it would be pointless.

Why it exists

An earlier version of this product claimed to be zero-knowledge and was not: the master password travelled to the server and was hashed there. Vault is the rewrite, started from an empty directory, with the claim made true first and everything else built around it.

The test it is held to is simple. If someone took a complete copy of the server — its disk, its database, its backups — they should get ciphertext and nothing more.

Principles

What Vault will and will not do

Encrypt first

Nothing readable leaves your device. Features that would need the server to see your data are not built.

Track nothing

No analytics, no cookies, no fonts or scripts from other companies. The page talks to this server and nowhere else.

Say what is not covered

Known risks are published, not buried. The security page lists them next to the protections.

What it runs on

Small, deliberate, and free to run

The whole system is small enough to hold in your head — which is part of the security.

One server

A single always-free cloud instance serves this site, the app and the API, behind a web server that sets every security header.

A managed database

Holds ciphertext only, on a private network. It is never on the web server's disk.

Daily encrypted backups

Exported every day to private storage, with restores tested. A backup holds the same ciphertext as the database.

Your secrets, readable only by you.
