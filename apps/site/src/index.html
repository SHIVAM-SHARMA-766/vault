How it works

Your password never leaves the browser

The server checks that you are you without ever learning the secret that proves it.

You type your master password

Your browser stretches it with 600,000 rounds of PBKDF2 into a master key. That pause before the vault opens is the same pause an attacker pays for every guess.

On your device

Two keys split off

One key unlocks your vault and stays put. A second, separate key — one that cannot be worked back to the first — is what the server sees to confirm it is you.

On your device

Only ciphertext is stored

Entries are sealed before upload. The server keeps encrypted blobs and a hash of the login key. A full breach of it yields nothing readable.

On the server

Honest about its limits

A security page that lists only strengths is a marketing page. Vault publishes the risks it does not protect against — including the biggest one — alongside the ones it does.
