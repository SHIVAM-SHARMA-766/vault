FAQ

Questions worth asking

Straight answers about what Vault does, what it does not, and why.

How do I get an account?

Accounts are currently opened by invitation. The person who runs this Vault creates a single-use code for you; enter it when you sign up. Codes expire, and each one works exactly once.

What happens if I forget my master password?

Use the recovery key you were shown at sign-up. It is the only other way in. There is no password reset, because the server cannot read your vault and so cannot let you back into it.

Can the person who runs Vault read my passwords?

No. The admin panel can see that an account exists, when it was created and last used, and how many items it holds — but not what they are, and not even your email address, which is stored only as a keyed hash.

If the server is hacked, what does the attacker get?

Encrypted entries, a hash of each user's login key, and vault keys that are themselves encrypted. To read anything they would have to guess a master password, paying 600,000 rounds of key stretching per guess, per account.

Why does unlocking take a second?

That is the key stretching happening on your device. It is deliberately slow, so that guessing passwords is slow too.

Why don't my entries show website icons?

Fetching an icon means asking someone else's server for it, which tells them which sites you have accounts with. Vault shows a coloured initial instead and makes no request to any third party.

Why do I have to unlock again after reloading the page?

Your keys are kept in memory and nowhere else — not in local storage, not in a cookie. A closed tab leaves nothing behind for someone with your laptop to find.

Does the page load anything from other companies?

No. No analytics, no fonts, no CDNs, no trackers. A strict Content-Security-Policy blocks the page from loading anything that does not come from this server.

Is there anything it does not protect against?

Yes, and it is stated plainly on the security page: a web app is only as trustworthy as the code it is served, and today that rests on a free dynamic-DNS name.
